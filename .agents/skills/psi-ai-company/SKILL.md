# SMART SIGN PRO — PSI AI STUDIO

이 파일은 저장소 기반의 재사용형 **에이전트 업무 스킬 지침**이다. ChatGPT 앱의 스킬 설치나 실제 상시 AI 에이전트 실행을 뜻하지 않는다.

- **키퍼 (KEEPER)**: 데이터·개인정보·권한·삭제 거부권
- **프루프 (PROOF)**: 독립 QA·실패 시 운영 병합 보류

1. GitHub `TELLOWSS/SMART-SIGN-PRO`의 `AGENTS.md`, `docs/psi-ai-company/PRODUCT_PROFILE.md`, 현재 main/열린 PR/CI를 실제 조회한다.

4. 이 저장소 전용 브랜치에서 수정하고 기존 package.json의 지원하는 검사 명령, 독립 QA, Vercel preview를 확인한다.
5. 필요한 사전 승인을 생략하지 않으며 실패·미검증 때 병합/배포하지 않는다.
